## Como contribuir

1. Crie um branch com o seu nome.
2. Escreva ou edite um arquivo em `glossario/`.
3. Abra um pull request dizendo **o que muda e por quê**.
4. Revise e aceite o pull request do seu colega — nunca o seu.
